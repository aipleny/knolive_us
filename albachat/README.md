# 알바챗 — 매장 아르바이트 관리

출퇴근 기록, 근무표, 시급·주휴수당·주급/월급 정산, 임금명세서, 표준근로계약서(내국인·외국인)를 한 곳에서 관리하는 웹 프로그램입니다.
POS에서 돌릴 수 있도록 가볍게 만들었습니다. 외부 라이브러리가 없고, Node.js만 있으면 실행됩니다.

## 실행

```bash
cd albachat
node server.js          # 기본 포트 8080 (PORT=9000 node server.js 로 변경)
npm test                # 급여 계산 테스트
```

| 주소 | 용도 |
|---|---|
| `http://매장PC:8080/` | **출퇴근 화면 (POS·태블릿).** 이름 → PIN → 출근/퇴근. 이번 주 근무표 표시 |
| `http://매장PC:8080/admin` | **관리자.** 오늘 현황, 직원, 근무표, 출퇴근 기록, 급여 정산, 근로계약서, 설정 |
| `http://매장PC:8080/me` | **직원 휴대폰 앱.** 휴대폰 번호 + PIN 로그인, 출퇴근 버튼, 내 근무 일정, 이번 달 예상 급여. 홈 화면에 추가하면 앱처럼 실행 |

### 처음 설정 순서
1. POS에서 `/admin` 접속 → 매장 이름과 관리자 비밀번호 설정
2. **설정**: 사업장 정보(대표자·주소·사업자번호·전화) 입력 → **이 기기를 출퇴근 단말기로 등록**
3. **직원**: 직원 등록 (이름, 연락처, 생년월일, 주민번호/외국인등록번호, 비상연락망, 시급, 주간 근무표, 출퇴근 PIN)
4. POS 브라우저 첫 화면을 `/` 로 두면 끝

## 기능
- **출퇴근**: POS 키오스크(PIN 5회 틀리면 5분 잠금) + 직원 개인 휴대폰. 등록하지 않은 기기에서는 직원 목록이 보이지 않습니다.
  휴대폰 출퇴근은 매장 와이파이 IP 또는 GPS 반경으로 제한할 수 있습니다.
- **근무표**: 직원별 주간 기본 근무표 + 날짜별 변경/휴무. 주간 근무표 인쇄.
- **출퇴근 기록**: 기간·직원별 조회, 관리자 수정(수정 이력 보관), 누락 기록 추가, CSV.
- **급여 정산**: 주급/월급/기간 지정. 기본급, 주휴수당, (5인 이상) 연장·야간 50% 가산, 공제(없음 / 3.3% / 4대보험 근로자분), 실지급액. 임금명세서 인쇄(법정 기재사항 포함), CSV.
- **근로계약서**: 고용노동부 표준근로계약서 양식 기반 5종 — 단시간근로자, 기간의 정함이 없는/있는 경우, 연소근로자(친권자 동의서 포함), 외국인근로자(한/영). 국적·나이·근무시간에 따라 양식을 자동으로 추천하고, 사업장·직원·근무표 정보를 채워 A4로 인쇄합니다.
- **알림**: 최저임금 미달(내년 최저임금 포함), 체류기간·보건증 만료, 유학·연수 비자 시간제취업 허가 확인, 연소근로자 제한, 퇴근 누락.

## 계산 기준
- 근무시간 = 퇴근 − 출근 − 휴게. 휴게는 기록 → 근무표 → (설정 시) 법정 최소 휴게(4시간 30분, 8시간 1시간) 순으로 적용.
- 주휴수당: 1주(월~일) 소정근로 15시간 이상 + 그 주 근무 예정일 개근 → `min(주 소정근로시간, 40) ÷ 40 × 8 × 시급`. 근무표가 없으면 실제 근무시간 기준. 그 주 일요일이 속한 정산 기간에 반영.
- 최저임금 기본값: 2026년 10,320원, 2027년 10,700원 (설정에서 수정).
- 4대보험 요율 기본값(2026, 근로자분): 국민연금 4.75%, 건강보험 3.595%, 장기요양 = 건강보험료 × 13.14%, 고용보험 0.9%. 근로소득 간이세액은 포함하지 않습니다.
- 휴일근로 가산, 중도 입·퇴사 일할, 시급 변경 이력은 반영하지 않습니다. 특수한 경우는 노무사·세무사 확인을 권합니다.

## 데이터와 보안
- 모든 데이터는 `data/albachat.json` 한 파일에 저장됩니다(경로는 `ALBACHAT_DATA`로 변경).
- 주민등록번호·외국인등록번호·계좌번호는 AES-256-GCM으로 암호화하며, 키는 `data/secret.key` 에 있습니다. **백업할 때 두 파일을 함께 보관하세요.** 키를 잃으면 암호화된 항목은 복구할 수 없습니다.
- 관리자 비밀번호와 PIN은 scrypt 해시로 저장합니다. 개인정보 열람·기록 수정은 변경 기록에 남습니다.
- 근로기준법상 근로자명부·임금대장·근로계약서는 퇴사 후 3년간 보존해야 하므로, 기록이 있는 직원은 삭제하지 않고 퇴사 처리합니다.

## 직원 휴대폰 앱으로 쓰려면 (인터넷 배포)
매장 와이파이 안에서는 `http://POS의IP:8080/me` 로 바로 쓸 수 있습니다.
밖에서도 쓰거나 GPS 제한·앱 설치(PWA)를 쓰려면 HTTPS가 필요합니다. 클라우드 서버(또는 매장 PC + Cloudflare Tunnel 등)에 올리고 도메인을 연결하세요.
HTTPS 뒤에서 실행할 때는 `ALBACHAT_SECURE_COOKIE=1`, 리버스 프록시를 쓰면 `ALBACHAT_TRUST_PROXY=1` 을 함께 설정합니다.
