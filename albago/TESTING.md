# ALBAGO 테스트 가이드 (서버 · 웹 · iOS · Android)

Mac mini 기준입니다. Windows도 같은 순서이며, 스크립트만 `.bat` 을 씁니다.

## 0. 준비물 (한 번만)
| 무엇 | 설치 | 용도 |
|---|---|---|
| Node.js 22.13 이상 | `brew install node` 또는 nodejs.org | 서버 실행 (내장 SQLite) |
| cloudflared (선택) | `brew install cloudflared` | 휴대폰에서 HTTPS 주소로 접속 (LTE에서도 됨) |
| Xcode (선택) | App Store | iOS 시뮬레이터 |
| Android Studio (선택) | developer.android.com | Android 에뮬레이터 |
| Expo 계정 (선택) | expo.dev 가입, `npm i -g eas-cli` | 실제 휴대폰용 앱 빌드 |

## 1. 서버 켜기
```bash
git clone <저장소> && cd knolive_us/albago
./scripts/start-test-server.sh          # 같은 와이파이에서만
./scripts/start-test-server.sh tunnel   # https://….trycloudflare.com 주소가 생김 (권장)
```
- 개발 모드라 문자·이메일을 실제로 보내지 않고, 인증번호가 서버 창과 화면 알림에 나옵니다.
- 데이터는 `albago/data-test/` 에 저장됩니다. 지우면 처음부터 다시 시작합니다.
- **tunnel 주소를 권장합니다.** HTTPS라서 휴대폰 위치(GPS), 앱 설치, 아이폰 Safari가 모두 정상 동작합니다. 같은 와이파이의 `http://192.168.x.x:8080` 주소는 위치 기능이 막힙니다.

## 2. 웹 테스트 (사장님 · 기록부 · 알바 웹)
1. 브라우저에서 `<서버 주소>/signup` 으로 가입합니다.
   - 테스트용 사업자번호: **123-45-67891** (검증번호가 맞는 예시 번호)
   - 휴대폰·이메일 인증번호는 화면 알림이나 서버 창에서 확인합니다.
2. `/owner` 에서 직원을 등록합니다. 아이디·비밀번호·PIN을 함께 넣어 두면 편합니다.
3. 근무표 → 일괄 등록으로 이번 주 근무를 넣습니다.
4. 왼쪽 아래 **[출퇴근 기록부 열기]** → 이름 → PIN → 출근·휴식·퇴근을 해 봅니다.
5. 휴대폰 브라우저로 `<서버 주소>/login` 에 알바 아이디로 로그인하면 알바 웹(시안 A)이 열립니다.
6. 급여 → [임금명세서 확정·앱 발송], 소통 → 경고·공지를 보내고, 알바 화면에서 받는지 확인합니다.

## 3. 알바 앱 — 가장 빠른 방법 (Expo Go)
```bash
cd albago/app && npm install
npx expo start --tunnel
```
1. 휴대폰에 **Expo Go** 앱(App Store·Play 스토어)을 설치하고 QR 코드를 찍습니다.
2. 로그인 화면 아래 "서버 주소"에 1번의 서버 주소를 넣습니다.
3. 로그인, 출퇴근 버튼, 근무표, 급여, 소통, 명세서·계약서 보기까지 확인할 수 있습니다.

> Expo Go에서는 **백그라운드 자동 출퇴근(지오펜스)과 푸시 알림이 동작하지 않습니다.** 이 두 가지는 4번의 개발 빌드가 필요합니다.

## 4. 알바 앱 — 개발 빌드 (자동 출퇴근·푸시까지)
```bash
cd albago/app
eas login
eas init                                         # 프로젝트 ID 생성 (푸시에 필요)
```
- **iOS 시뮬레이터 (Mac):** `npx expo run:ios`
  - 시뮬레이터 메뉴 Features → Location → Custom Location 에 매장 좌표를 넣으면 "도착"이, 멀리 옮기면 "이탈"이 일어납니다. 자동 출퇴근을 테스트할 수 있습니다.
- **Android 에뮬레이터:** `npx expo run:android`
  - 에뮬레이터 ⋯ → Location 에서 좌표를 바꿔 같은 방식으로 테스트합니다.
- **실제 Android 폰:** `eas build -p android --profile preview` 로 APK를 받아 설치합니다(QR·링크 제공).
- **실제 iPhone:** Apple 개발자 계정(연 99달러)이 필요합니다.
  - `eas device:create` 로 아이폰을 등록합니다.
  - `eas build -p ios --profile development` 로 빌드해 설치합니다.

실제 휴대폰에서 자동 출퇴근을 테스트하는 순서:
1. 사장님 설정 → 매장 위치에서 **[지금 위치로]** 를 누르고, 반경을 100m로 둡니다.
2. 알바 앱에서 위치 권한을 **"항상 허용"** 으로 줍니다.
3. 근무 시작 30분 전 이내에 매장 밖에서 안으로 들어와 봅니다.

## 5. 확인 체크리스트
- [ ] 가입(사업자번호·문자·이메일) → 로그인 이메일 인증번호
- [ ] 직원 등록, 알바 가입 신청 → 승인
- [ ] 근무표 일괄 등록, 날짜별 수정, 브레이크타임
- [ ] 기록부: 출근·휴식·퇴근, PIN 틀림 5회 잠금
- [ ] 앱: 출근·휴식·퇴근, 자동 출근·이탈·복귀·퇴근 알림
- [ ] 급여: 시급제·월급제, 주휴수당, 5인 이상 가산, 4대보험, 엑셀 3종
- [ ] 임금명세서 발송 → 앱에서 열람·PDF 저장
- [ ] 근로계약서 작성 → 앱 전달 → [받았습니다]
- [ ] 소통: 경고·공지 발송 → 앱 [확인했습니다] → 기록 무결성 확인
- [ ] 알림: 근무 시작 전, 퇴근 미기록, 근무표 변경
- [ ] 한국어/영어 전환

## 6. 실제 운영으로 갈 때
- 문자(솔라피), 이메일(SMTP), 국세청, 카카오 키를 넣습니다. 방법은 README의 "운영 설정"에 있습니다.
- `ALBAGO_DEV` 는 빼고, albago.kr 도메인에 HTTPS를 붙여 실행합니다.
- `data/` 폴더(DB와 secret.key)를 꼭 백업하세요.
