# ALBAGO 알바고 (albago.kr)

사업자 회원 전용 아르바이트 관리 서비스입니다. 출퇴근 기록부, 앱 자동 출퇴근, 근무표, 급여(주휴수당·가산수당·4대보험), 엑셀, 임금명세서, 표준근로계약서를 지원하고, 한국어와 영어를 모두 지원합니다.

```
albago/
  server.js        서버 (Node.js 22.13+, 외부 패키지 없음, 내장 SQLite)
  lib/calc.js      근무시간·브레이크타임·야간·연장·주휴수당 계산
  lib/insurance.js 4대보험 가입 판정·근로자/사업주 부담·두루누리
  lib/xlsx.js      엑셀(.xlsx) 생성
  lib/services.js  이메일(SMTP)·문자(솔라피)·국세청 사업자 상태조회·카카오 주소→좌표
  public/          웹 화면 (사장님·기록부·알바 웹·가입), i18n.js(한/영)
  app/             알바용 모바일 앱 (Expo / React Native) — app/README.md
  windows/         매장 PC(POS)용 Windows 설치 파일 ALBAGO-Setup.exe — windows/README.md
  API.md           앱 ↔ 서버 규격
  test/            자동 테스트 (npm test)
```

## 실행
```bash
cd albago
npm run dev     # 개발 모드: 문자·이메일 대신 인증번호를 화면·서버 로그에 표시
npm start       # 운영
npm test        # 테스트 29개
```
| 주소 | 화면 |
|---|---|
| `/` | 소개 |
| `/signup` | 사업자 회원가입: 사업자번호 확인 → 휴대폰 인증 → 이메일 인증 → 아이디/비밀번호 |
| `/login` | 로그인. 매장코드(사업자번호) + 아이디 + 비밀번호. 사장님은 이어서 이메일 OTP 입력(이 기기 30일 기억 가능) |
| `/owner` | 사장님: 오늘 · 직원 · 근무표 · 출퇴근 기록 · 급여 · 근로계약서 · 설정 |
| `/kiosk` | 출퇴근 기록부. 사장님이 POS·사장님 폰·매장 폰에서 등록하면, 알바가 이름과 PIN으로 출근·휴식·퇴근을 찍습니다 |
| `/join` | 알바 가입 신청(매장코드 필요) → 사장님 승인 |
| `/staff` | 알바 웹(앱 미설치 시). 자동 출퇴근은 앱에서만 됩니다 |

## 주요 기능
- **출퇴근 방법 3가지**
  1. 매장 공용 기기(출퇴근 기록부): 이름 + PIN을 누릅니다. 기록부 모드를 끝내려면 사장님 비밀번호가 필요합니다.
  2. 알바고 앱 자동 출퇴근: 매장 반경(기본 100m)에 들어오면 근무 시작 30분 전부터 자동 출근합니다. 근무 종료 10분 전부터는 매장을 나가면 바로 퇴근 처리합니다. 근무 중간에 나가면 15분을 기다렸다가, 돌아오지 않으면 나간 시각으로 퇴근 처리합니다. 출퇴근할 때 앱 알림("출근했어요" / "퇴근합니다")이 뜹니다. 시간은 모두 설정에서 바꿀 수 있습니다.
  3. 앱 버튼 출근·휴식·퇴근: 설정하면 매장 반경 안에서만 누를 수 있습니다.
- **근무표**: 월 달력에서 날짜별로 수정합니다. 일괄 처리는 직원 여러 명 × 기간 × 요일(평일/주말/매일 또는 날짜를 직접 선택)로 "빈 날만 등록 / 덮어쓰기 / 직원별 기본 패턴 적용 / 삭제" 중에 고릅니다. 브레이크타임은 시간 구간으로 여러 개 넣을 수 있습니다.
- **급여**: 월급, 주급, 기간 지정으로 정산합니다. 휴게는 실제 휴식 기록 → 사장님 입력값 → 근무표 브레이크타임 → 법정 최소 휴게 순서로 반영하고, 야간 시간은 휴게를 빼고 셉니다.
  - 주휴수당: 주 15시간 이상이고 예정일 개근일 때 지급합니다.
  - 연장·야간 가산: 5인 이상 사업장으로 설정한 경우에만 계산합니다.
  - 공제: 3.3%, 또는 4대보험 + 직원별로 입력한 근로소득세 중에서 고릅니다.
- **4대보험(별도 로직)**
  - 월 60시간 기준으로 가입 여부를 판정합니다. 국민연금은 만 18~59세, 고용보험은 만 65세 이후 신규 채용이면 제외합니다.
  - 외국인은 체류자격·국적에 따라 확인이 필요한 항목으로 표시합니다. 직원별로 가입/미가입을 직접 지정할 수도 있습니다.
  - 국민연금 기준소득월액 상·하한, 장기요양, 고용보험 사업주분(1.15%), 산재(업종 요율), 두루누리 80% 지원을 반영합니다. 결과는 근로자 부담, 사업주 부담, 총 인건비로 나눠 보여 줍니다.
- **엑셀**: 출퇴근 기록부 + 근무일지(직원×날짜 표), 급여대장 + 4대보험 판정표.
- **임금명세서**: 근로기준법 시행령 제27조의2 기재사항을 담았고, 외국인 직원이면 한/영 병기로 인쇄합니다.
- **근로계약서**: 고용노동부 표준근로계약서 5종입니다(단시간, 정규, 기간제, 연소근로자+친권자 동의서, 외국인 한/영). 요일별 근무시간과 브레이크타임이 자동으로 들어갑니다.

## 추가된 기능 (v2)
- **사업장 규모와 가산수당 규칙** (설정 → 사업장 규모 · 가산수당 규칙)
  - 최근 1개월 출퇴근 기록으로 상시근로자 수를 계산해 참고로 보여 줍니다(시행령 제7조의2: 연인원 ÷ 가동일수, 미달일수 1/2 규칙). 앱에 없는 근로자 수를 더할 수 있습니다.
  - 5인 이상 적용 여부는 사장님이 체크합니다.
  - 가산율(%)은 사장님이 정합니다: 연장, 야간, 휴일(8시간 이내/초과), 단시간 근로자의 정한 시간 초과. 비워 두면 법정 기준을 따릅니다.
  - 공휴일 유급휴일(5인 이상 의무)과 근로자의 날(규모 무관) 유급휴일을 지원합니다.
  - 공휴일 목록은 2026·2027년 불러오기 버튼이 있습니다. 대체·임시 공휴일은 정부 발표와 맞는지 확인하세요.
  - 직원별 주휴일 요일에 일하면 휴일근로로 계산하고, 연장근로와 중복해서 가산하지 않습니다.
- **시급제 / 월급제** (직원 정보)
  - 월급제는 월급을 그 달 재직 일수로 일할 계산하고, 주휴수당은 월급에 포함된 것으로 봅니다.
  - 통상시급 = 월급 ÷ 월 소정근로시간(직접 입력, 또는 (주 소정시간 + 주휴) × 365/7/12, 기본 209시간). 이 금액으로 가산수당과 최저임금을 확인합니다.
- **소통 채널** (사장님 탭 "소통", 알바 앱·웹)
  - 사장님 → 알바: 공지(전 직원), 지시사항, 메시지, 경고, 징계, 해고 통보
  - 알바 → 사장님: 메시지, 건의, 결근 사유서, 근무 변경 요청
  - 사진·PDF 첨부(3개, 각 5MB)
  - 근거 보존:
    - 기록은 삭제·수정할 수 없습니다. 보낸 시각, 읽은 시각, 확인(수령) 시각과 IP를 저장합니다.
    - 매장별 해시 체인을 걸어 두어, [기록 무결성 확인]으로 DB가 변조되었는지 검사할 수 있습니다.
    - 경고장, 징계 통보서, 해고 통지서, 업무 지시서, 결근 사유서를 서명란이 있는 서면으로 인쇄할 수 있습니다.
    - 해고 통보를 쓸 때는 근로기준법 제23·26·27조 안내가 뜹니다.
  - 엑셀(소통 기록)로 내보내기, 앱 푸시 알림(Expo, EAS projectId 필요)

## 운영 설정 (환경변수)
| 변수 | 내용 |
|---|---|
| `SMTP_HOST` `SMTP_PORT` `SMTP_USER` `SMTP_PASS` `SMTP_FROM` | 이메일 인증·로그인 OTP 발송 (465 SSL / 587 STARTTLS) |
| `SOLAPI_KEY` `SOLAPI_SECRET` `SOLAPI_SENDER` | 휴대폰 인증 문자 (솔라피, 발신번호 사전 등록 필요) |
| `NTS_SERVICE_KEY` | 국세청 사업자등록 상태조회 (공공데이터포털). 없으면 사업자번호 형식·검증번호만 확인 |
| `KAKAO_REST_KEY` | 매장 주소 → 좌표. 없으면 매장에서 [지금 위치로] 또는 위도·경도 입력 |
| `ALBAGO_DATA` | 데이터 폴더 (기본 `./data`: `albago.db`, `secret.key`) |
| `ALBAGO_SECURE_COOKIE=1` | HTTPS 운영 시 |
| `ALBAGO_TRUST_PROXY=1` | Nginx 등 리버스 프록시 뒤에서 실행 시 (접속 IP 판별) |

`data/secret.key`는 주민번호·외국인등록번호·계좌번호 암호화와 로그인 토큰 서명에 쓰입니다. **DB와 함께 반드시 백업하세요.** 키를 잃으면 암호화된 항목을 복구할 수 없습니다.

## 알아 둘 점
- 자동 출퇴근은 휴대폰 GPS·OS의 지오펜스 기능에 의존합니다. 실내에서는 30~50m 반경이 잘 인식되지 않을 수 있어 100m 이상을 권장합니다. 앱의 백그라운드 위치 사용은 Google Play·App Store 심사에서 사용 목적 설명이 필요합니다(app/README.md 참고).
- 근로소득 간이세액표는 내장하지 않았습니다. 직원별 월 소득세를 입력하면 그 금액을 공제합니다. 휴일근로 가산과 중도 입·퇴사 일할 계산은 포함하지 않습니다.
- 4대보험 요율 기본값은 2026년 기준입니다. 매년 설정에서 갱신하세요.
- 이용약관·개인정보 처리방침 문서는 서비스 오픈 전에 별도로 준비해야 합니다(주민번호 수집 근거 포함).
